# sNyteXx Termix Plugins

A custom [Termix](https://github.com/Termix-SSH/Termix) plugin registry. Every version listed here was
reviewed, is pinned by its `sha256`, was built by the Termix release workflow (GitHub build provenance)
and is signed with this registry's key. Termix checks the signature before it installs anything.

## Add it to Termix

In Termix: **Plugins → Registries → Add registry**, paste

```
https://raw.githubusercontent.com/sNyteXx/termix-registry/main/snytexx/index.json
```

then **Check**, compare the key id with the one below, and **Trust and add**.

| Key id             | Public key                                     |
| ------------------ | ---------------------------------------------- |
| `dbd4cfde7466862c` | `kMtE8LuWicRQV5UnDM5y0Q+LwV1XY9uRjkkNFHney4g=` |

If Termix shows any other key id, do not add the registry.

The plugins then show in **Plugins → Browse**, and new versions as updates. No developer mode is needed.

## How it works

```
plugin repo                        this repo
Release workflow ──▶ GitHub release v1.2.3 (.tmxplug + build provenance)
                                        │
          PR: snytexx/plugins/<id>.json pins version + sha256
                                        │  Check plugin entry: sha256, manifest, provenance, maintainer
                                        ▼
                          review the source at the tag, merge
                                        │  Sync: download, check sha256 again, sign, write index.json
                                        ▼
                     snytexx/index.json ──▶ Termix (checks signature against the pinned key)
```

- `snytexx/plugins/<id>.json`: one file per plugin, the only thing edited by hand.
- `snytexx/index.json`: generated by the Sync workflow. Never edit it by hand.
- `keys/snytexx.pub`: the public key. The private key exists only as the Actions secret
  `TERMIX_SNYTEXX_SIGNING_KEY`.
- `scripts/`: sync, validation and the PR check, adapted from
  [Termix-Registry](https://github.com/Termix-SSH/Termix-Registry) (Apache-2.0, see NOTICE).

Adding a plugin or a version: see [MAINTAINING.md](MAINTAINING.md).
